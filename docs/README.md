# FoundIt deliverables map

FoundIt follows the forge deliverables list. Where the project already had an
equivalent, this map points to it instead of duplicating it.

Requirement ids: `R1` in these docs means "Requirement 1" in
`.kiro/specs/campus-lost-found/requirements.md` (R5d means Requirement 5d, and so on).
